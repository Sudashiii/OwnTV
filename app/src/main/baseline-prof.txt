# Baseline Profile for OwnTV's own code: the launcher (app), the renderer (layout-render) and the
# layout model (layout-model) all live in dev.owntv. The libraries bring their own profiles.
# AGP expands the wildcards against the release dex and ships the result in assets/dexopt/ and in
# the .dm files next to the APK (build/outputs/apk/release/baselineProfiles/).
# A plain install (adb install, PackageInstaller) ignores the profile in the APK: ProfileInstaller
# hands it to ART on first launch and the next background dexopt compiles it. An install that
# passes the .dm (adb install-multiple app.apk app.dm) compiles it right away (speed-profile). The
# release workflow publishes the .dm files and the in-app updater installs the matching one (Updater.kt).
# Rule syntax: https://developer.android.com/topic/performance/baselineprofiles/manually-create-measure
#
# Every class (loaded at start-up) and every method (hot, start-up and post-start-up) in dev.owntv.
